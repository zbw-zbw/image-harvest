Image Harvest는 스마트 이미지 다운로더입니다. 웹페이지의 모든 이미지를 자동으로 찾아 저장합니다. 다른 도구가 놓치는 CSS 배경, 지연 로딩 이미지, Shadow DOM 이미지까지 포함해 하나의 ZIP으로 묶어 일괄 다운로드할 수 있습니다. 크기/형식 필터링, 여러 탭 동시 추출, 유사 이미지 중복 제거, AI 스마트 태깅과 즐겨찾기 관리를 갖췄습니다. 디자이너, 리서처, 쇼핑몰 운영자, 콘텐츠 큐레이터를 위해 만들어졌습니다. 가입 없이 무료로 사용할 수 있습니다.

🔍 스마트 이미지 추출

웹페이지의 모든 이미지를 자동으로 찾아냅니다. 일반 이미지는 물론 CSS 배경, 반응형 이미지, 고해상도 변형 이미지까지 포함됩니다. Shadow DOM과 iframe까지 꼼꼼히 스캔해 하나도 빠뜨리지 않습니다. Pro 사용자는 라이브 모니터링을 켜서 스크롤 중 새로 로딩되는 이미지까지 자동으로 감지할 수 있습니다.

🔗 링크 뒤의 원본 이미지 가져오기

썸네일이 상세 페이지로 연결되는 사이트(Reddit 스타일 갤러리, 상품 목록)는 고화질 이미지를 클릭 너머에 숨겨둡니다. Image Harvest가 그 링크를 대신 따라갑니다: 이미지 직접 링크는 매 스캔마다 자동으로 추출되고, 이미지나 링크를 우클릭하면 패널로 바로 전송되며, Pro 사용자는 갤러리 링크 전체를 한 번에 분석해 각 상세 페이지의 원본 이미지를 가져올 수 있습니다.

🎛️ 강력한 필터와 정렬

크기(소/중/대/특대/사용자 지정), 형식(JPG/PNG/WebP/SVG/GIF), 비율(정방형/가로형/세로형/파노라마), URL 키워드로 자유롭게 필터링하세요. 스마트 그룹화는 도메인·형식·크기 범위·탭 기준 분류를 지원합니다(Pro). 크기, 형식 또는 원본 순서대로 정렬할 수 있습니다. "표시 중만 보기"를 켜면 현재 화면에 있는 이미지만 집중해서 볼 수 있습니다.

📥 이미지 일괄 다운로드

개별 이미지를 다운로드하거나 여러 이미지를 하나의 ZIP 파일로 묶어 한 번에 내려받을 수 있습니다. 시각적 진행률 표시줄로 다운로드 진행 상황을 실시간 확인하세요. 무료 사용자는 한 번에 최대 30장까지 일괄 다운로드할 수 있으며, Pro 사용자는 무제한입니다.

🌐 멀티 탭 추출

열려 있는 여러 브라우저 탭에서 이미지를 한 번에 추출합니다. 탭을 하나씩 옮겨 다닐 필요 없이 열려 있는 모든 탭을 동시에 스캔하고 이미지를 한 번에 받으세요. 여러 페이지에 걸친 조사, 쇼핑 비교, 콘텐츠 큐레이션에 딱 맞습니다.

🔎 유사 이미지 감지

고급 퍼셉추얼 해싱 알고리즘으로 시각적으로 비슷한 이미지를 자동 감지하고 묶어줍니다. 중복되거나 거의 동일한 변형 이미지를 받는 일을 막고, 다운로드 전에 불필요한 이미지를 걸러 시간과 저장 공간을 절약합니다.

🔍 역방향 이미지 검색

특정 이미지가 온라인 어디에 등장하는지 빠르게 찾아냅니다. 무료 사용자는 Google 이미지 검색을 이용할 수 있습니다. Pro 사용자는 Google 이미지, TinEye, 바이두, Yandex 등 4개 검색 엔진을 잠금 해제하여 이미지 출처 추적, 더 높은 해상도 버전 찾기, 진위 확인까지 폭넓게 커버합니다.

✨ 일괄 하이라이트

패널에서 여러 이미지를 선택하면 웹페이지에서 해당 이미지들을 동시에 하이라이트합니다. 하이라이트된 위치로 자동 스크롤되어 빠르게 찾고 확인할 수 있습니다. 다운로드 전 대량 이미지 검토에 가장 적합한 도구입니다.

⭐ 이미지 컬렉션

마음에 드는 이미지를 사용자 지정 태그와 메모와 함께 로컬 컬렉션에 저장하세요. 저장한 이미지를 언제든 탐색·검색·필터링하고, 컬렉션 전체를 ZIP 파일로 일괄 내보낼 수도 있습니다. 브라우저를 떠나지 않고 나만의 이미지 라이브러리를 만들어 보세요.

🎨 색상 추출

각 이미지에서 지배적인 색상 5가지를 자동으로 추출해 패널에서 바로 확인합니다. HEX 색상 코드를 한 번의 클릭으로 복사해 디자인 작업, 브랜드 분석, 창작 프로젝트에 활용하세요.

🤖 AI 이미지 태깅

AI가 모든 이미지에 스마트 태그를 생성합니다. 이미지를 열지 않고도 어떤 내용인지 바로 파악할 수 있습니다. 개별 태깅과 선택 이미지 일괄 태깅을 모두 지원하고, AI 태그로 이미지를 필터링·검색할 수 있습니다. 무료 사용자에게는 월간 할당량이 제공되며 Pro 사용자는 무제한입니다.

🦅 Eagle 내보내기

인기 디자인 에셋 관리 앱인 Eagle로 이미지를 바로 보내세요. 내보내기 시 이미지와 함께 메타데이터, AI 태그, 원본 URL이 포함되어 Eagle 라이브러리가 항상 정돈된 상태로 유지됩니다. 선택한 여러 이미지를 한 번에 내보내는 것도 지원합니다. 무료 사용자는 최대 5장까지, Pro 사용자는 무제한으로 내보낼 수 있습니다.

⚡ 일괄 작업

여러 이미지를 선택한 뒤 일괄 즐겨찾기 추가, 일괄 AI 태깅, 일괄 삭제 같은 작업을 한 번에 실행하세요. 하나씩 클릭하는 반복 작업은 그만, 대량의 이미지를 다룰 때 작업 속도가 크게 향상됩니다.
