Image Harvest はスマート画像ダウンローダー。Web ページ上のすべての画像を自動で検出し、他のツールが見逃しがちな CSS 背景・遅延読み込み画像・Shadow DOM 画像も含めて ZIP にまとめて一括保存できます。サイズや形式でのフィルタリング、複数タブの一括抽出、類似画像の重複検出、AI 自動タグ付けやコレクション管理を搭載。デザイナー、リサーチャー、EC サイト運営者、コンテンツ制作者のために作られました。登録不要で無料で使えます。

🔍 スマート画像抽出

Web ページ上のすべての画像を自動検出 —— 標準画像はもちろん、CSS 背景、レスポンシブ画像、高解像度バリアントも対象。Shadow DOM や iframe の奥までスキャンして取りこぼしゼロを実現。Pro ユーザーはライブモニタリングを有効にでき、スクロール中に新しく読み込まれた画像も自動検出します。

🔗 リンクの先にあるオリジナル画像を取得

サムネイルから詳細ページへ遷移するサイト（Reddit 型ギャラリー、商品一覧）では、高画質画像が毎回のクリックの奥に隠れています。Image Harvest がそのリンクを代わりにたどります：画像への直リンクは毎回のスキャンで自動抽出、任意の画像やリンクを右クリックすればそのままパネルへ送信、Pro ユーザーはギャラリーリンクを一括解析して各詳細ページのオリジナル画像を取得できます。

🎛️ 強力なフィルタリングと並べ替え

サイズ（小/中/大/特大/カスタム）、形式（JPG/PNG/WebP/SVG/GIF）、レイアウト比（正方形/横長/縦長/パノラマ）、URL キーワードで柔軟にフィルタリング。スマートグループ化ではドメイン・形式・サイズ帯・タブ別の分類に対応（Pro）。サイズ、形式、元の順序で並べ替え可能。「表示中のみ」をオンにすると現在の画面内の画像だけに絞り込めます。

📥 画像の一括ダウンロード

1 枚ずつのダウンロードにも、複数枚を 1 つの ZIP ファイルにまとめての一括ダウンロードにも対応。進捗バーでダウンロード状況をリアルタイムに確認できます。無料ユーザーは 1 回につき最大 30 枚まで一括ダウンロード可能。Pro ユーザーは無制限です。

🌐 マルチタブ抽出

開いている複数のブラウザータブから同時に画像を抽出。タブをひとつずつ切り替える必要はありません —— 開いているすべてのタブをまとめてスキャンし、すべての画像を一度にダウンロード。ページ横断のリサーチ、買い物比較、コンテンツ整理に最適です。

🔎 類似画像検出

高度な知覚ハッシュアルゴリズムにより、見た目が似ている画像を自動検出してグループ化。重複やほぼ同一のバリアント画像のダウンロードを防ぎ、ダウンロード前に冗長な画像を特定することで時間とストレージを節約します。

🔍 逆画像検索

ある画像が Web 上のどこに使われているかを素早く調査。無料ユーザーは Google 画像検索を利用できます。Pro ユーザーは Google 画像検索、TinEye、百度画像検索、Yandex の 4 エンジンをアンロック —— 画像の出どころ追跡、より高解像度なバージョンの発見、真贋の確認まで幅広くカバーします。

✨ 一括ハイライト

パネルで複数の画像を選択すると、Web ページ上でそれらをまとめてハイライト表示。ハイライトした画像へ自動スクロールするので、場所をすばやく特定して確認できます。ダウンロード前の大量チェックに最適な機能です。

⭐ 画像コレクション

お気に入りの画像をカスタムタグ・メモ付きでローカルコレクションに保存。保存した画像はいつでも閲覧・検索・フィルタリングでき、コレクション全体を ZIP ファイルとして一括エクスポートすることも可能です。ブラウザーから出ずに自分専用の画像ライブラリを作れます。

🎨 カラーアクセス

各画像から dominant カラー上位 5 色を自動抽出し、パネル上で直接カラー パレットを表示します。HEX コードはワンクリックでコピーでき、デザイン作業、ブランド分析、創作活動にそのまま活かせます。

🤖 AI タグ付け

AI があらゆる画像にスマートタグを生成 —— 画像を開かずとも内容がひと目でわかります。単体タグ付けも、選択画像の一括タグ付けも、AI タグによる絞り込み・検索も自由自在。無料ユーザーには月間利用枠が付与され、Pro ユーザーは無制限です。

🦅 Eagle への書き出し

人気のデザイン素材管理ツール「Eagle」へ画像を直接送信。エクスポートには画像だけでなくメタデータ・AI タグ・ソース URL も一緒に付与されるため、Eagle ライブラリが常に整理された状態に保たれます。選択画像の一括書き出しにも対応。無料ユーザーは最大 5 枚まで書き出し可能。Pro ユーザーは無制限です。

⚡ 一括操作

複数の画像を選択して、お気に入りへの一括追加、AI タグの一括付与、一括削除などの操作をまとめて実行。1 件ずつの反復作業から解放され、大量の画像処理でも効率が大きく上がります。

🌍 15 言語対応

English、简体中文、繁體中文、日本語、Español、한국어、Português、Français、Deutsch、Italiano、Русский、Nederlands、हिन्दी、العربية、ไทย の 15 言語に完全翻訳済み。ブラウザーの言語を自動判定するので設定は不要です。

🔒 プライバシー第一

Image Harvest はすべての処理をブラウザー内で完結させます。画像・URL・個人情報がデバイスの外に出ることはありません。任意の匿名 利用統計（イベント回数のみ —— URL・画像・識別子は一切含まない）は「設定 → 改善に協力」から有効化でき、既定ではオフです。
